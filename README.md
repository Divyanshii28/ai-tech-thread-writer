# AI Tech Trend Thread Writer

An AI-powered content generation project focused on creating viral-style tweets and short threads tailored for Indian tech audiences.

## Features
- Viral-style tweet generation
- Human-like conversational tone
- Audience-focused outputs
- Trend-aware AI prompting
- Twitter/X optimized formatting

## Concepts Used
- Prompt Engineering
- Generative AI
- AI Content Optimization
- Audience-Aware AI Generation

## Example Output

> Most fresher resumes look identical now.
>
> Same certifications.
> Same projects.
> Same buzzwords.
>
> Proof of work is becoming the real differentiator.

---

> Indian students are learning AI like it's another subject.
>
> The people winning are using AI daily to build things.

## Learnings
- Prompt engineering
- AI workflow design
- Audience-focused AI generation
- Content optimization

## Future Improvements
- Trend analysis
- Hook generation
- Viral score prediction
- LinkedIn post generation
